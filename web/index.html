01 / THE PROJECT

What Baymax is
being built to explore.

Baymax is a fine-tuning experiment built around a 1-billion-parameter Llama 3.2 base model. The repository records a 4-bit base, LoRA settings, a pinned dataset revision, and an offline inference path.

The training data’s usage rights and the proposed input-to-target mapping still need review. Training is gated until both are resolved. A recorded greeting smoke run proves a model generated text on this machine; it does not show that the output is correct or safe.

03 / CLEAR BOUNDARIES

Useful evidence.
Honest limits.

01

Not a medical tool

Baymax does not diagnose, treat, or replace a qualified health professional. Its output may be wrong, unsafe, or outdated.

02

Training is gated

Dataset rights and the proposed schema mapping need review. Public availability does not establish permission to train.

03

Separate experiments

The repository’s Flask, Pinecone, and Groq RAG demo is a distinct legacy experiment. It does not serve the fine-tuned model.

04

No clinical evaluation

There is no independently reviewed held-out evaluation set, verified reproducible training runtime, or clinical validation.
